# 栈与递归

### 1、采用递归算法解决的问题


> 所谓的递归是指，若在一个函数、过程或者数据结构定义的内部又直接（或间接）出现定义本身的应用，则称他们是递归的。在下面三种情况下，常常使用递归的方法。
>



#### 1.1、定义是递归的


有很多数学函数是递归定义的，如阶乘函数：



```cpp
long int f(int n)
{
	if(n==0)
	  return 1;	
	else
	  return n*f(n-1);
}
```



#### 斐波那契数列：


```cpp
int fib(int n)
{
	if(n==0)
		return 0;
	if(n==1)
		return 1;
	if(n>1)
		return fib(n-1)+fib(n-2);
}
```



对于类似这样的复杂问题，若能够分解成几个相对简单且解法相同或类似的子问题来求解，便称作递归求解。例如计算4！时先计算3！，然后再进一步分解进行求解，这种求解-分解的策略叫做分治法。  
采取分治法进行递归求解的问题需要满足以下三个条件：



+ 能够一个问题转变成一个新问题，而新问题与原问题的解法相同或类同，不同的仅是处理的对象，并且这些处理对象更小且变化有规律。
+ 可以通过上述转化而使问题简化。
+ 必须有一个明确的递归出口，或称为递归的边界。



分治法求解递归问题的算法的一般形式为：



```cpp
void p(){
	if(递归结束条件成立) 可直接求解；  //递归终止的条件
	else p(较小的参数);     //递归步骤
}
```



可见上述两个例子与此一般形式相对应。



#### 1.2、数据结构是递归的


某些数据结构本身具有递归的特性，则他们的操作可递归地描述。  
例如，对于链表，其结点LNode的定义由数据域data和指针域next组成，而指针域next是一种指向LNode类型的指针，即LNode的定义中又用到了其自身，所以链表是一种递归的数据结构。



#### 遍历输出链表中各个结点的递归算法：


```cpp

void TraverseList(LinkList p){
	if(p==NULL)  return;
	else{
		cout<<p->data<<endl;
		TraverseList(p->next);
	}
}
```



#### 1.3、问题的解法时递归的


> 有一类问题，虽然问题本身没有明显的递归结构，但用递归求解比迭代求解更简单，如Hanoi塔问题、八皇后问题、迷宫问题。
>



#### Hanoi塔问题


思路：  
把n-1个饼移到B,再把第n个饼移到C，最后把n-1个饼移到C。



```cpp
#include <stdio.h>
int count;
void hanoi(int n,char a,char b,char c)
{//将塔座a上的n个圆盘按规则搬到c，b做辅助塔
   if(n==1)
   {
   	printf("第%d次，%c柱-->%c柱\n",++count,a,c);
   }	
   else
   {
   	hanoi(n-1,a,c,b);
   	printf("第%d次，%c柱-->%c柱\n",++count,a,c);
   	hanoi(n-1,b,a,c);
   }
} 

int main()
{
	int num;
	printf("请输入A柱汉诺塔盘子的数量：");
	scanf("%d",&num);
	count=0;
	hanoi(num,'A','B','C');
	return 0;
}
```



#### 求N个数中的最大值


求 元素序列55，33，22，77，99，88，11，44中的最大值。



分析：



假设元素序列存储在数组a中，数组a中n个元素的最大值可以通过将a[n-1]与前n-1个元素最大值比较之后得到，当n=1时findmax(a,n)=a[0],当n>1时，有findmax(a,n)=(a[n-1]>findmax(a,n-1)?a[n-1]:findmax(n-1))/



也就是说，数组a中只有一个元素时，最大者是a[0]，超过一个元素时则要比较最后一个元素a[n-1]与前n-1个元素中的最大值，其中较大的一个既是所求，而n-1个元素的最大值需要继续调用findmax函数。



```cpp
#include<stdio.h>
int findmax(int *a,int n)
{
	int m;
	if(n<1)
	  return a[0];
	else
	{
	  m=findmax(a,n-1);
	  return a[n-1]>=m?a[n-1]:m;	
	}
}
int main()
{
	int a[]={55,33,22,77,99,88,11,44},n;
	n=sizeof(a)/sizeof(a[0]);
	printf("数组中最大的元素为：%d\n",findmax(a,n));
	return 0;
}
```



**数制转换**



使用递归函数实现将十进制整数转换为二进制数。



整数部分：



除二取余法，函数DectoBin的定义如下 :void DectoBin(int num)



当num==0时回推结束，开始递推，否则，将商作为新的除数，即调用函数DectoBin(num/2)，同时输出每层的余数。



```cpp
#include<stdio.h>
void DectoBin(int num); 
int main()
{
	int n;
	printf("请输入一个十进制数：");
	scanf("%d",&n);
	printf("二进制数是：");
	DectoBin(n); 
	printf("\n");
	return 0;
}
void DectoBin(int num)
{
	if(num==0)
	  return;
	else
	{
		DectoBin(num/2);
		printf("%d",num%2);
	}
}
```



说明：因为当商为0时，递推阶段结束，需要停止递推，也不需要返回值，所以只要一个空的返回语句，return;



小数部分：



乘二取整法， 用2乘以十进制小数，得到一个整数和一个小数，保存整数，然后继续用2乘以剩下的小数。重复下去。直到小数部分为0或者满足一定的精度为止。得到的整数部分就是对应的二进制小数。



```cpp
#include<stdio.h>  
#include<math.h>  
#define N 8  
int main()  
{  
     int a,b[N+1],i,k=0,zs;  
     int count=0;//用来控制精度   
     double x,xs;  
     for(i=0;i<=N;i++)  
     {  
        b[i]=0;  
     }  
     printf("请输入一个十进制小数：");  
     scanf("%lf",&x);  
     zs=int(x);//整数部分   
       
     xs=x-zs;   //小数部分   
     printf("zs:%d xs:%lf\n",zs,xs);  
     printf("二进制数：");  
     while(zs)   //对整数部分进行处理   
     {  
        b[k++]=zs%2;  
        zs/=2;  
     }  
     for(i=k-1;i>=0;i--)  
     {  
        printf("%d",b[i]);  
     }    
     printf(".");  
     while(xs&&count<=4)  
     {  
            xs*=2;  
            a=int(xs);  
            xs=xs-a;  
              
            printf("%d",a);   
            count++;  
     }   
     printf("\n");  
}
```



#### 求最大公约数


两个整数M和N的最大公约数具有一个性质，用C语言描述如下。



```cpp
#include<stdio.h>

int gcd(int m,int n)
{
	if(m>n)
	{
		return gcd(m-n,n);
	}
	else if(m<n)
	{
		return gcd(m,n-m);
	}
	else
	{
		return m;
	}
}
```

**杨辉三角**



杨辉三角具有的性质：



（1）第N行的数字为N个



（2）第N行数字和为2（n-1）次方



（3）每个数字等于上一行的左右两个数字的和



......



直接上代码：



```cpp
#include<stdio.h>  
#define N 8  
int main()  
{  
    int a[N+1][N+1],i,j;  
    for(i=0;i<=N;i++)  
    {  
        a[i][i]=a[i][0]=1;  
    }  
    for(i=1;i<=N;i++)  
    {  
        for(j=1;j<i;j++)  
        {  
            a[i][j]=a[i-1][j]+a[i-1][j-1];  
        }  
    }  
    printf("杨辉三角如下：\n");  
    for(i=0;i<=N;i++)  
    {  
        for(j=0;j<=i;j++)  
        {  
            printf("%3d",a[i][j]);  
        }  
        printf("\n");  
    }  
}
```
